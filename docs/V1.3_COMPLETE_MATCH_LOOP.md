# Faces & Heels v1.3 — Complete Match Loop

## Purpose

v1.3 converts the Stone vs Viper vertical slice from a move-resolution demo into a match that can start Neutral, change control repeatedly, resolve reactions and pins, recover from low-stamina/dead states, and end with a winner.

The visual/HUD/sprite work from v1.1.1 is retained.

## What from the playtest hole list is included

### P0 — included

- Opening Neutral BGD roll.
- Explicit H / N / L roles shown in the fighter HUD.
- Real control transfer between Stone and Viper.
- Failed offense opens a real Reaction window.
- Successful Reaction transfers H to the reactor.
- Failed/declined Reaction maintains H/L when H/L already exists.
- Prone ending position creates Pin eligibility automatically, regardless of move name.
- Real opposed three-count Pin procedure.
- Kickout at count 1, 2, or 3 based on opposed rolls.
- Pinfall Match Complete state.
- Kickout aftermath: both prone, N/N, previously pinned wrestler +10 STA and next action.
- Post-kickout Scramble Up bridge so the limited digital move catalog cannot deadlock from both wrestlers being prone.
- Crowd-resource-to-stamina action: spend 1 Pop/Heat for +10 STA.
- No-legal-action safety valve: Catch Breath resets to Neutral.
- 0 STA finish pressure: if the target has 0 STA, H is limited to prone-making setup moves; if the target is already prone the pin opportunity is mandatory.

### P1 — included

- Character Main Stats now feed move modifiers.
- Conditioning now feeds attack and Reaction targets.
- Successful moves roll a move-specific damage die against the targeted body threshold.
- A body-point mark is added only if the damage roll exceeds the threshold.
- Body-point marks affect Pin rolls using the source rule:
  - pinning wrestler subtracts Core marks;
  - pinned wrestler subtracts all body marks.
- Successful moves can remove stamina from the move taker.
- Selected crowd-building Common Moves earn Pop/Heat.
- The Legendary/Special move earns Pop/Heat.
- Pop/Heat can be spent for +1 on a move roll (maximum one in this playtest ruleset).
- Pop/Heat can be spent for +10 STA.

## Provisional v1.3 digital rules

The original source explicitly leaves several formulas unresolved. v1.3 therefore labels the following choices as **playtest rules, not final canon**.

### Stat modifier

```text
modifier = floor((raw Main Stat - 10) / 2)
```

This preserves 2d12-style raw Main Stats while keeping d20 modifiers playable.

### Conditioning

```text
CON = 10 + Fortitude modifier
```

This is chosen instead of `10 + raw Fortitude`, which would make many d20 attacks effectively impossible.

### Normal move attempt

```text
d20 + move-stat modifier + optional 1 Pop/Heat >= defender CON
```

Ties meet the target and succeed.

### Reaction

Shove Counter is the v1.3 placeholder Reaction move:

```text
d20 + Power modifier >= original attacker CON
cost = 5 STA
```

Success transfers H to the reactor. Failure retains existing H/L. If the failed action began from a special N/N next-action state, a failed/declined reaction returns to Neutral.

### Damage

Each move has a playtest damage die (`d8`, `d10`, or `d12`).

```text
if damage roll > targeted body threshold:
    add 1 body mark
```

Body marks are capped at 3 per tracked body region for this digital prototype.

### Stamina damage

Each digital move has a separate playtest `staminaDamage` value. This is intentionally data-driven so it can be replaced once the creator approves the canon rule.

### Crowd resource

- pool cap: 5;
- maximum roll boost in v1.3: 1 Pop/Heat;
- 1 Pop/Heat can be spent for +10 STA;
- selected crowd-pleasing Common Moves and all Legendary/Special moves can gain 1.

### Pin ties

The source says the pinned wrestler must **win** a roll to kick out. Therefore a tie does not count as a defender win; the referee count continues.

### Post-kickout Scramble Up

The source says both wrestlers become prone and the previously pinned wrestler gets the next move. The current small demo move catalog contains no move that can be initiated prone. To preserve the source result without deadlocking the digital vertical slice, v1.3 offers a zero-cost **Scramble Up** system action to the previously pinned wrestler before that next move.

This bridge should be reevaluated when the full Common Move catalog exists.

## Automated full-match simulation requirement

Beginning with v1.3, a build is not considered match-loop complete unless the automated simulation suite passes.

### Release gate

- **Minimum:** 500 complete simulated matches.
- **Default local/CI target:** 1,000 complete simulated matches.
- Every simulation must reach `MATCH_COMPLETE` with a winner.
- No simulation may exceed the safety cap of 600 engine steps.
- The simulator must exercise Neutral rolls, offense, target selection, reactions, pins, kickouts, recovery, post-kickout scrambles, control changes, and match completion.
- Any no-legal-action state must have a deterministic escape path.
- A failed simulation fails the build.

Run:

```bash
npm test
```

or only the simulation suite:

```bash
npm run test:sim
```

Override the count:

```bash
FH_SIM_MATCHES=500 node test-simulations.mjs
FH_SIM_MATCHES=2000 node test-simulations.mjs
```

## v1.3 simulation baseline

The packaged build was validated with **1,000 complete Stone vs Viper matches**.

Observed baseline:

- completed matches: **1,000 / 1,000**;
- Stone wins: **544**;
- Viper wins: **456**;
- average engine steps: **29.1**;
- maximum engine steps: **204**;
- average Pin attempts: **6.27**;
- average Reactions attempted: **3.80**;
- average control changes: **4.56**;
- average Neutral rolls: **2.50**;
- average recovery actions: **0.90**;
- average post-kickout Scramble Up actions: **5.91**.

The win split is not a balance target; it is a regression baseline. Balance should be tuned only after the provisional math is approved.

## UX flow after v1.3

```text
NEUTRAL
  ↓ opposed BGD + Agility mod
H / L ESTABLISHED
  ↓
H chooses move
  ↓
move succeeds ──────────────── move fails
  ↓                              ↓
damage + stamina             L Reaction / Pass
  ↓                              ↓
if prone → PIN?              success → L becomes H
  ↓                              ↓
continue H offense           failure/pass → H retained
  ↓
PIN
  ↓
count 1 → count 2 → count 3
  ↓                 ↓
kickout             pinfall
  ↓                 ↓
both prone N/N      MATCH COMPLETE
pinned +10 STA
pinned gets next action
  ↓
Scramble Up if needed
```

# Faces & Heels v1.1 — Wrestler Identity + Contact Anchor Specification

## Objective

Scale the v1.0 procedural sprite direction without allowing every wrestler to read as the same mannequin in different colors, and improve paired-contact reliability without replacing authored wrestling choreography.

## Identity layer

Character identity is procedural and independent of move animation. The shared skeleton remains compatible across wrestlers.

Stone identity cues:
- broader powerhouse proportions;
- red/gold bandana and gear;
- gold knee stars;
- wrist lightning;
- long blond layered hair;
- handlebar facial hair;
- small chest-hair detail.

Viper identity cues:
- leaner proportions;
- black/red gear;
- procedural snake-sleeve marks;
- fang/chevron knee detail;
- facial scar;
- dark mohawk and beard.

Future wrestlers should add identity through a CharacterDefinition layer rather than forking animation clips.

## Contact anchor schema

Every atlas JSON contains an `anchors` array with one object per frame. Coordinates are local to the 320×400 source frame.

Required anchor names:
`head`, `neck`, `chest`, `upper_chest`, `waist`, `l_shoulder`, `r_shoulder`, `l_hand`, `r_hand`, `hands_center`, `l_knee`, `r_knee`, `l_ankle`, `r_ankle`.

## Runtime solver

Authored root choreography remains authoritative. During defined contact windows, the runtime:

1. converts frame-local anchors into normalized arena coordinates;
2. compares attacker and defender contact anchors;
3. clamps correction to a small safe range;
4. applies a smooth envelope at the start/end of contact;
5. shifts mostly the defender and slightly the attacker;
6. never replaces the underlying animation or rules state.

This is a correction layer, not full inverse kinematics.

## Debugging

`?debugAnchors=1` renders contact points over the arena. This mode is development-only and makes it possible to tune contact rules without guessing from sprite overlap.

## v1.1 contact mappings

- Forearm Smash: attacker right hand → defender head.
- Running Clothesline: attacker right hand → defender upper chest.
- Vertical Suplex: attacker hands center → defender upper chest/waist across lift phases.
- Body Slam: attacker hands center → defender chest/waist.
- Dragon Screw: attacker hands center → defender right ankle in the authored demo clip.
- Ground Headlock: attacker right hand → defender head, left hand → defender right shoulder.
- Pin: attacker chest → defender upper chest, light correction only.

## Move-set growth rule

Growing the move library must not regrow the routine HUD. If >4 legal moves exist, the routine action dock shows four useful moves plus a `MORE MOVES` control. Filters become visible only in the expanded move browser.

## Acceptance criteria

- 32 generated atlases exist and have per-frame anchors.
- all contact metadata frame counts match the associated atlas frame counts.
- Stone and Viper are distinguishable in grayscale silhouette/gear detail as well as color.
- fixed-target new moves do not introduce target pickers.
- paired-contact correction is bounded and does not visibly teleport wrestlers.
- debug anchors can be enabled without changing match logic.
- Smart Flow tests continue to pass.

# Example Data

The JSON files in this folder exist to demonstrate how the software could store game content.

**Important:** these files are not a substitute for the rules. Any value not explicitly present in the original PDF is a placeholder unless the creator later approves it.

- `styles.example.json` uses the canonical style names from the source but intentionally leaves style mechanics undefined.
- `wrestlers.example.json` uses Stone and Viper as mockup/testing characters; their stats and cosmetics are not canon.
- `moves.example.json` contains illustrative move records to test the data model. The source PDF does not define these move details.

# Visual Direction Reference

This folder contains generated concept images from the design conversation. They are references, not exact production assets.

## 01_high_fidelity_discord_concept.png

Shows the maximum-visual-fidelity idea: realistic wrestler portraits, dense match dashboard, ring scene, logs, body diagrams, action controls. Useful for understanding feature possibilities, but too busy and too art-intensive for the current target.

## 02_programmer_art_concept.png

Shows what a more realistic small-team / programmer-created version might look like: flat/vector wrestlers, simplified ring, practical HUD, lower art burden.

## 03_clean_match_ui_concept.png

**Current preferred UI reference.** The user positively responded to this simplified direction. It reduces permanent information, removes the full-time match log/body diagrams, keeps wrestler status compact, makes the ring central, and uses large contextual action controls with a bottom move sheet.

## Production direction

Aim for a polished version of the third concept rather than recreating the first concept's photorealism.

The eventual game can exceed the programmer-art image through:

- consistent bespoke wrestler sprite templates;
- good typography;
- responsive motion;
- strong impact effects;
- polished sound;
- restrained color and hierarchy;
- clean mobile touch behavior.

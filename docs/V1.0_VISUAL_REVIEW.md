# Faces & Heels v1.0 — Visual Review

This review uses the scoring categories defined by the Visual Polish + UI Redo specification.

## Canonical screen review

### Normal turn
- Ring remains the largest visual region.
- Four legal moves are surfaced directly; category filters are absent because they are unnecessary.
- Move controls use narrow semantic accent rails rather than full bright borders.
- Primary match information is confined to two compact fighter HUDs.

### Forearm Smash selected
- Head is represented as a fact, not a target-selection control.
- Target, stamina cost and Power modifier are condensed into one metadata line.
- Roll d20 is the single dominant primary action.
- Boost is visibly secondary.

### Dragon Screw target choice
- Only the actual decision — Left Leg / Right Leg — is presented as equal-weight controls.
- No fixed facts become extra buttons.

## Remaining visual opportunities

The next visual work should be refinement rather than another architecture reset:
- more wrestler-specific gear/personality variation;
- more crowd variation/signs;
- extra expression frames for spectacle moves;
- contact-anchor/IK-style corrections for grapples with very different body proportions;
- optional higher-resolution 768×768 paired-move atlases for tablets.

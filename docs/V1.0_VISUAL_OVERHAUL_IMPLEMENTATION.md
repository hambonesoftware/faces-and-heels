# Faces & Heels v1.0 — Visual Overhaul Implementation

This build executes the Visual Polish + Button + Overall UI Redo specification while retaining the v0.9 Smart Flow and paired-contact animation architecture.

## Implemented in v1.0

### Wrestler renderer v2
- Replaced boxed abdominal cells with large sculpted torso planes.
- Added tapered limb geometry with separate shadow/midtone/highlight planes.
- Added overlapping shoulder caps and joint contact shadows.
- Enlarged and redesigned fists for stronger silhouette/readability.
- Rebuilt boots with cuff, shaft, toe, sole, lace marks, and highlight planes.
- Rebuilt faces with stronger jaw/cheek/brow planes and expression readability.
- Rebuilt hair/facial hair using layered masses.
- Added dark silhouette outline and two-sided cyan/red arena rim lighting.
- Retained fully procedural Pillow rendering; no external character artwork.

### Full animation atlas regeneration
All 24 Stone/Viper atlases were regenerated through the v1.0 renderer:
- idle
- Forearm Smash attacker/defender
- Vertical Suplex attacker/defender
- Dragon Screw attacker/defender
- Ground Headlock attacker/defender
- prone
- pin
- kickout

### HUD / overall screen
- Reduced fighter-HUD chrome and removed routine READY labels.
- Increased visual priority of the arena.
- Added layered far/mid/near crowd treatment.
- Added haze, light beams, lighting rig, center spotlight and vignette.
- Reworked ring mat, apron, posts and ropes.
- Kept details in drawers rather than permanent match chrome.

### Button system
- Removed category filters from routine turns when four or fewer legal moves are available.
- Rebuilt move controls around a dark action surface + narrow semantic accent rail.
- Strike accent = red; Grapple = cyan; Special = gold.
- Replaced the selected-move three-box fact layout with one metadata line.
- Strengthened one-primary-action hierarchy for Roll d20.
- Preserved contextual gold Pin opportunity and reaction states.
- Enlarged critical/interactive typography.

### Runtime game feel
- Added stronger impact bloom.
- Added strike directional streaks.
- Added heavy-slam shock ring.
- Increased move-class camera push.
- Retained hit stop, camera shake, mat bounce and particles.

## UX behavior intentionally unchanged
- Fixed targets auto-resolve.
- Forearm Smash does not ask the player to select Head.
- Dragon Screw presents Left Leg / Right Leg because it is a real choice.
- Pin remains contextual.
- Optional crowd-resource spend defaults to none.
- Match Log preserves transparent rules/math.

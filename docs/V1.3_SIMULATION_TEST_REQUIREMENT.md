# v1.3 Full-Match Simulation Test Requirement

## Mandatory release gate

Every match-engine release must run automated complete matches, not only unit tests for individual functions.

- Minimum release gate: **500 matches**.
- Default suite: **1,000 matches**.
- Recommended balance/economy sweep before a major release: **5,000+ matches**.

## A simulation fails if

- no winner is reached;
- `MATCH_COMPLETE` is not reached;
- engine steps reach 600;
- `ACTION_SELECT` exists without an active wrestler;
- the active wrestler has no legal action and no valid recovery/scramble/Neutral transition;
- a Pin enters a non-terminal state with no next count or kickout;
- a Reaction leaves conflicting H/L roles;
- both wrestlers are H or both are L;
- stamina becomes negative;
- crowd resource exceeds its cap or becomes negative;
- body marks exceed the playtest cap;
- a match state becomes non-deterministic when supplied the same roll sequence.

## Coverage expectations

Across the batch, the simulator should observe:

- both wrestlers winning at least one match;
- successful and failed moves;
- successful and failed Reactions;
- H/L transfers;
- Pin attempts;
- kickouts at multiple counts;
- at least one pinfall;
- Neutral rolls;
- crowd-resource use;
- stamina recovery;
- post-kickout Scramble Up;
- body-point accumulation.

## Current command

```bash
npm run test:sim
```

Default count is 1,000. Set `FH_SIM_MATCHES` to override.
